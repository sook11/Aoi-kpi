ติดตั้งแอปลงมือถือ

เพิ่มไอคอน AOI KPI บนหน้าจอหลักเพื่อเปิดใช้ได้เร็ว

ตอนนี้แอปเปิดจากไฟล์ในเครื่อง ยังติดตั้งบนมือถือไม่ได้ ต้องนำแอปขึ้นเว็บก่อน แล้วหน้านี้จะแสดง QR code ให้สแกน

สแกนเพื่อเปิดแอปบนมือถือ

Android (Chrome)

  1. เปิดลิงก์แอปด้วย Chrome
  2. แตะปุ่ม ⋮ มุมขวาบน
  3. เลือก “เพิ่มลงในหน้าจอหลัก” หรือ “ติดตั้งแอป”
  4. แตะ “เพิ่ม”

iPhone (Safari)

  1. เปิดลิงก์แอปด้วย Safari
  2. แตะปุ่มแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น)
  3. เลือก “เพิ่มไปยังหน้าจอโฮม”
  4. แตะ “เพิ่ม”
